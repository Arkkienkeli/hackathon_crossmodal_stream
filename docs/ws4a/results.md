# WS4A results — the full HepG2 run

*Two complete runs of the whole grid: 6 targets × 5 descriptions × 4 models, real and
shuffled labels, 25 cross-validation folds each — 240 model fits per run. One with a
fixed grid ("untuned"), one with Optuna at 20 trials per fold ("tuned"), the shuffled
control given the identical budget in both. Ran as a 30-task SLURM array,
[runbook §12](ws4a-runbook.md#12-fast-path-the-ml-stage-as-an-array-across-nodes).
Figures and tables regenerated by `scripts/ws4a_report.py`.*

!!! warning "Read the gap, never the score"
    Every number on this page is `gap_vs_permuted` = score on real labels − score on
    the same labels shuffled. A raw score of 0.70 with a shuffled score of 0.68 is
    nothing. See [for dummies](ws4a-for-dummies.md#the-trap-and-why-you-must-not-believe-a-score-on-its-own).

**Mechanism of action is where the signal is.** Every description beats its own

grid comes close except liver toxicity from chemistry.

## The question the project exists to answer

![Incremental value of morphology](../assets/figures/ws4a-incremental-value.png)

Chemistry is free — no cells, no microscope, no plates. So the test that matters is
not "does morphology beat chance", it is **does morphology beat, or add to, what the
chemical structure already gives you.**

| target | chemistry alone | + morphology | **Δ** | morphology alone − chemistry alone |
|---|---|---|---|---|
| **moa-fine** | +0.175 | **+0.318** | **+0.143** | **+0.093** |
| tox_pulmonary_toxicity | +0.092 | +0.146 | +0.055 | −0.027 |
| tox_renal_toxicity | +0.147 | +0.118 | −0.030 | −0.139 |
| tox_infertility | +0.193 | +0.129 | −0.064 | −0.181 |
| tox_liver_toxicity | +0.244 | +0.170 | −0.074 | −0.232 |
| tox_cardiotoxicity | +0.141 | +0.057 | −0.084 | −0.146 |

**The honest headline, in one sentence:**

> Cell Painting morphology adds real information about a compound's **mechanism of
> action** — +0.143 on top of chemical structure, with all four models agreeing — and
> adds **nothing** about the toxicity endpoints in this dataset, where it usually
> makes prediction worse.

Two qualifications that belong in the same breath:

- **Morphology adds nothing on top of transcriptomics.** `expression + morphology`
  (+0.344) is barely above `expression` alone (+0.339). If you already have RNA-seq,
  the image is not adding to it here. Morphology is far cheaper per sample, which is
  the practical argument, not an information-content one.
- **The toxicity endpoints are predicted by chemistry, and only by chemistry.**
  That is what a QSAR baseline is *supposed* to do, and adding 636 imaging features
  to ~70 compounds makes it worse — the classic small-n dilution.

## Tuning: did the search buy signal, or bias?

![Tuning audit](../assets/figures/ws4a-tuning-audit.png)

The tuned run searched 20 Optuna trials per fold, **and gave the shuffled-label
control the identical budget** — the equality that makes the comparison meaningful.

| | |
|---|---|
| median change in score on **shuffled** labels | **−0.0003** |
| median change in the honest gap | +0.0055 |
| rows where tuning helped | 65 of 120 |
| verdicts | 31 improved, 62 unchanged, 27 degraded, **0 `bias`** |
| gaps clearing zero | 56 → **56** |
| degenerate rows | **10 → 0** |

Three conclusions, and only the third is a win:

1. **Tuning manufactured no measurable bias at this budget.** The shuffled-label
   scores did not move (−0.0003), and not one of the 120 rows earned the `bias`
   verdict. At 20 trials the search is small enough to be honest. That is a
   *measurement*, not an assumption — and it is the number to quote if anyone asks
   why the budget is 20 and not 500.
2. **Tuning produced no new findings.** The count of gaps clearing zero is
   **identical**, 56 before and 56 after. Tuning moved numbers; it did not turn a
   null into a result anywhere.
3. **Tuning fixed ten broken models.** All ten degenerate rows in the baseline were
   XGBoost, and all ten were on the two targets with the smallest minority class
   (`moa-fine`, 14 positives; `tox_liver_toxicity`, 16). At `min_child_weight = 5`
   no split satisfied the constraint, so the model returned the majority class every
   fold and scored exactly 0.500 ± 0.000. The tuned run searches from 1 and produced
   **zero** such rows.

!!! note "This corrects an earlier claim on this site"
    A preliminary `--quick` comparison (2 blocks, 2 models, 1 repeat) suggested tuning
    produced *more* degenerate rows than the baseline. **The full run says the
    opposite: 10 → 0.** The `--quick` result was an artefact of its reduced fold
    count and is not evidence about the real run. Any statement to the contrary on
    this site is superseded by this page.

## The controls, drawn against their nulls

![Tier 1 controls](../assets/figures/ws4a-controls.png)

A permutation null is usually reported as a p-value and believed or not. Drawn, it
settles three arguments at once.

**Left — the control that removed a finding.** AJIVE's joint rank of 4 sits *inside*
the distribution the same analysis produces when the compound correspondence is
destroyed. The null reaches 4 on its own. p = 0.095.

**Middle — a number that survived.** The permutation CCA statistic for the first
component is 3.59 against a null that rarely exceeds 3 (p = 0.017). Note what this
panel does *not* show: the correlation itself, r₁ = 0.903. Quoted alone that number
would mean nothing, which is why the PC budget is capped at 10.

**Right — the statistic that cannot tell data from noise.** Plain RV on *random
noise of the same shape* scores as high as it does on the real data, and on two of
three pairs **higher**:

| pair | plain RV, real | plain RV, random noise | adjusted RV, real | adjusted RV, noise |
|---|---|---|---|---|
| morphology ~ chemistry | 0.2300 | **0.2313** | 0.0214 | −0.0012 |
| expression ~ chemistry | 0.2779 | **0.2744** | 0.0350 | 0.0003 |
| morphology ~ expression | 0.0855 | **0.2449** | 0.0157 | 0.0001 |

This is the single most direct demonstration on the site of why the reported effect
is `rv_adj`. Plain RV is measuring the *shape* of the tables, not their agreement.

## Why every number is paired with a control

![Why subtract](../assets/figures/ws4a-why-subtract.png)

If the shuffled-label score were always 0.500, you could compare a raw score to 0.5
and skip all of this. **It is not.** Across this grid it runs from **0.377 to 0.598**
— a quarter of the whole scale — with a mean of 0.483.

That spread is not noise to be averaged away. It is structure specific to each
target, block and model: how the folds happen to split, how imbalanced the labels
are, how many features the model can overfit. The only way to remove it is to
measure it for that exact combination and subtract it, which is what the shuffled run
does.

The right panel is the same point as a picture: **height is not the finding, distance
above the diagonal is.** Several points sit at a real score near 0.62 and are grey —
their control scored just as well.

## Do four different models agree?

![Model concordance](../assets/figures/ws4a-model-concordance.png)

With intervals this soft, agreement between methods that fail in different ways is
worth more than any single interval.

| | elastic_net | linear_svm | sparse_plsda | xgboost |
|---|---|---|---|---|
| **elastic_net** | 1.00 | 0.87 | 0.75 | 0.47 |
| **linear_svm** | 0.87 | 1.00 | 0.73 | 0.50 |
| **sparse_plsda** | 0.75 | 0.73 | 1.00 | 0.53 |
| **xgboost** | 0.47 | 0.50 | 0.53 | 1.00 |

*(Spearman ρ of the honest gap across the 30 target × block cells)*

The three linear-family models rank the grid very similarly (ρ = 0.73–0.87). XGBoost
agrees much less (ρ = 0.47–0.53) — expected, since a boosted tree finds different
structure than a penalised linear model, and a useful reminder that "four models
agree" is a real statement here rather than four views of the same fit.

The cells at the top of the right panel — `moa-fine` with morphology, with
morphology+chemistry, with expression — are the ones where **all four sit right of
zero**. Those are the results to quote.

## How certain is any of this?

![Gap uncertainty](../assets/figures/ws4a-gap-uncertainty.png)

Every gap is a mean over 25 folds. The intervals shown are
±1.96 × √(se²real + se²shuffled), with se = fold sd ⁄ √25.

**They are approximate and anti-conservative.** Cross-validation folds share training
data, so they are not independent, and there is no unbiased estimator of the variance
of k-fold cross-validation (Bengio & Grandvalet 2004). The true intervals are wider
than drawn. Read them as *"is this anywhere near zero"* — never as a p-value, and
never to claim one result is significantly better than another.

That caveat is why the signal map reports **model consensus** as well: four
independent model families clearing zero is a stronger statement than any single
interval on this page.

## Tier 1 — do the modalities agree at all?

Separate from prediction: do compounds that look alike under the microscope also have
similar gene-expression changes?

| pair | adjusted RV | RV p | Mantel r | Mantel p | PROTEST p |
|---|---|---|---|---|---|
| morphology ~ expression | 0.0157 | 0.097 | 0.202 | **0.0001** | **0.011** |
| morphology ~ chemistry | 0.0214 | 0.190 | 0.086 | 0.147 | 0.097 |
| expression ~ chemistry | 0.0350 | **0.0001** | 0.094 | **0.033** | **0.0001** |

**Morphology and expression agree — weakly but real.** Two of three tests are
significant; the adjusted RV is 0.016, i.e. the shared structure is a small fraction
of either table. Morphology and chemistry do not significantly agree at all, which is
consistent with the prediction result: the image is seeing something the structure is
not.

**The controls collapse, as they must.** Scrambled compound pairing and random blocks
give adjusted RV between −0.0012 and +0.0016 on every pair. If they had not, the
pipeline would be wrong rather than the biology.

### Joint structure: a control that changed the conclusion

AJIVE reports a **joint rank of 4** between morphology and expression. The
permutation null — the same analysis with the compound correspondence destroyed —
reached a joint rank of **4 as well** (mean 1.55, p = 0.095).

**So "four joint components" is not reported as a finding.** This is the clearest
example in the project of a control changing an answer, and it is exactly the claim
that would have been made without one.

Permutation CCA is the one place a strong-looking number survives its control: the
first canonical correlation is r = 0.90 with p = 0.017, the second r = 0.75 with
p = 0.033. Both beat their own permutation nulls. Note the r on its own means
nothing — [the PC budget is capped at 10 precisely because CCA reaches r ≈ 0.9 on
permuted null data](ws4a-toolchain.md) when it is not.

## Can we see genes, morphology features and chemistry in one space?

Yes for two of the three, no for the third — and the "no" is the more useful result.

`scripts/ws4a_crossmodal.py` builds the leading **canonical axis** between morphology
and expression: a single direction along which the two modalities agree most, with
every compound placed on it by *both* measurements at once. Chemistry is deliberately
kept out of the fit and related to the finished axis afterwards, which is what allows
the figure to say anything about all three.

Only this pair earned the right to be drawn. Its permutation CCA statistic beat its
null (p = 0.017); AJIVE's joint rank did not (p = 0.095), so the AJIVE joint space is
not plotted as though it were structure.

![Cross-modal embedding](../assets/figures/ws4a-crossmodal-embedding.png)

### The features at each end of that axis

Which individual genes and measurements define the shared direction? The answer is
**not** "the ones with the biggest loadings". At n = 119 with 41,780 genes, the
largest correlation obtainable from pure noise is enormous, because the axis is
*fitted* to maximise agreement and can align with almost any single feature by
chance.

So every panel carries a threshold measured rather than assumed: destroy the compound
correspondence, rebuild the entire axis, record the largest absolute loading anywhere
in that block, repeat 200 times, take the 95th percentile. That is family-wise error
control at 5 %, and it is brutal.

![What defines the shared axis](../assets/figures/ws4a-crossmodal-features.png)

| block | features above the null threshold | threshold |
|---|---|---|
| **morphology** | **14 of 636** | ±0.921 |
| expression | **0 of 41,780** | ±0.908 |
| chemistry (ECFP) | **0 of 1,024** | ±0.981 |

**The shared axis is interpretable in morphology, and in nothing else.** The 14
survivors are strikingly coherent — they are not a scatter of unrelated measurements:

| feature | loading |
|---|---|
| `Nuc · Texture · AngularSecondMoment 10 03 256 · DNA` | −0.978 |
| `Nuc · Texture · AngularSecondMoment 10 01 256 · DNA` | −0.978 |
| `Nuc · Texture · AngularSecondMoment 10 02 256 · DNA` | −0.975 |
| `Cyto · AreaShape · Zernike 8 0` | −0.973 |
| `Cells · Texture · InfoMeas2 3 03 256 · DNA` | +0.962 |
| `Cells · Correlation · K · DNA/ER` | −0.952 |
| `Cells · Granularity · 12 · AGP` | −0.947 |

Nuclear **DNA texture** (three angular-second-moment measurements at the same scale,
differing only in angle — a chromatin-homogeneity readout), **cell and cytoplasm
shape** (Zernike moments), and DNA–ER **co-localisation**. That is a coherent
chromatin-organisation and nuclear-morphology phenotype, not a grab bag.

**No individual gene survives.** Not one of 41,780. That is not a failure of the
method — it is a statement about the biology available at this sample size: the
transcriptional side of the shared axis is **diffuse**. It is carried by many genes
each contributing a little, not by a handful of drivers. Anyone presenting a
"top 20 genes" list from data of this shape should be asked what their null was.

**No ECFP bit survives either**, which is consistent with everything else on this
page: chemistry does not align with the morphology–expression shared axis. The
`morphology ~ chemistry` adjusted RV was also not significant (p = 0.19).

### The caveat this analysis exposed about r

The observed first canonical correlation is **r₁ = 0.903**. The 95th percentile of
its own permutation null, under the same 10-PC budget, is **0.902**.

**r₁ on its own is at the edge of what noise produces.** The pair is significant by
the pooled Winkler statistic (3.59, p = 0.017), which uses all three components and
has more power — but this is the sharpest possible demonstration of the warning that
has been in the config from the start: *PC-CCA reaches r ≈ 0.9 on permuted null data*.

If you quote one number from this section, quote the p-value, never the 0.903.

### Running it

```bash
bash scripts/ws4a.sh crossmodal --cell-line hepg2 --null-reps 200
```

~20 s. Writes `crossmodal_loadings_<cell>.csv` (only the features that beat their
null) and the two figures above. `--modalities` and `--third` change which pair the
axis is built from and which block is related to it afterwards.

## Reproducing this page

```bash
bash scripts/ws4a.sh report \
    --baseline /work/Results/ws4a/ml --tuned /work/Results/ws4a_tuned/ml \
    --stats /work/Results/ws4a/stats --cell-line hepg2 \
    --out /work/Results/ws4a/report
```

Writes `signal_map_hepg2.csv`, `incremental_value_hepg2.csv`,
`gap_intervals_hepg2.csv` and the seven figures above. `--stats` is optional and adds
the Tier 1 control figure. It refits nothing — it reads the
two merged tables — so it runs on a laptop against results copied off the cluster.
