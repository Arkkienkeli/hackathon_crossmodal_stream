# Hackathon cross-modal stream
## Drug response prediction as a cross-modal alignment signal

Leverage drug response data as a supervised signal to align morphological representations from LINCS and OpenScreen with transcriptomic representations from TAHOE, and assess whether the modalities capture complementary or redundant information about drug response and mechanisms of action, while identifying genes and gene programs encoded in morphological phenotypes.
